## Что это

Это сборка **Cascade**, которую ведём мы. Сам Cascade — это панель управления
для WireGuard и AmneziaWG: создаёт туннели, выдаёт конфигурации клиентам,
маршрутизирует трафик по доменам и странам, управляет файрволом и TLS в одном
месте.

Мы поставляем её с **полностью русским интерфейсом**, набором **исправлений
клиентской маршрутизации** и **доработками алиасов**, которые делают правила
маршрутизации размером со страну пригодными к использованию. Движок не тронут —
это тот же Cascade, у которого убраны острые углы, собранные нами в работе.

## Что мы изменили

### Русский интерфейс

Переведена вся панель администратора — каждый экран, каждая строка, 1 427
ключей в 46 файлах. Это настоящая локализация, а не подмена текста: ключи лежат
в `internal/frontend/i18n/messages.{en,ru}.json`, собираются в сгенерированный
каталог, а всё отсутствующее откатывается на английский. Ошибки бэкенда идут
через тот же каталог, поэтому сообщения валидации тоже на русском.

### Исправления клиентской маршрутизации

Три дефекта делали выдаваемые конфигурации тихо неправильными. Каждый найден
измерением, а не догадкой.

**Критичные сервисы больше не выбрасываются из туннеля.** Алиас размером со
страну даёт слишком много маршрутов, чтобы отдать их телефону, поэтому префиксы
округляются наружу до `/16`. Округление не умеет отличать «российское» от
«соседнего с российским»: для РФ оно захватило все девять опубликованных
IPv4-диапазонов Telegram и диапазоны Meta — ни один из которых не является
российским. Эти сервисы уходили напрямую и ложились на сетях, где их душат.
Теперь префиксы, которые при округлении задевают защищённый диапазон, остаются
точными. Цена на реальном списке РФ: 2 053 → 2 101 маршрут, все двенадцать
защищённых диапазонов остаются в туннеле.

Округление выбрано осознанно. Если вместо него аккуратно суммировать
дополнение, ошибка уйдёт в безобидную сторону — но замеры это исключают:
российское адресное пространство слишком размельчено, и такое сжатие затягивает
61 % российских адресов обратно в туннель при пороге 1 % и 100 % при 2 %.

**IPv6 забирается в туннель, а не утекает.** Выход несёт только IPv4. Если всё
равно отдавать `::/0`, клиент направит IPv6 в туннель, который его не понесёт,
и приложения упадут на IPv4 — тогда весь зарубежный трафик пойдёт через VPN.
Если же `::/0` убрать, IPv6 утечёт напрямую к местному провайдеру, где сервисы
Google душат: YouTube встаёт, Gemini сообщает об отсутствии интернета, а
системная проверка связи падает, хотя IPv4 работает. Забирать — меньшее зло.

**MTU клиента по умолчанию 1280**, а не доверие пути в 1500 байт. Замерено
пингами с флагом DF по живым клиентам: ноутбук проносил внешние пакеты 1500
байт, что подтверждает накладные 80 байт, а телефон — только 1360. Без MTU в
конфиге клиент берёт 1420 и выдаёт ровно 1500 — WireGuard ставит DF, поэтому
каждый превышающий пакет отбрасывался: мелкие запросы работали, крупные
передачи и звонки нет. 1280 — минимум IPv6 и наибольшее значение, влезающее в
каждый измеренный нами путь.

### Доработки алиасов

- **Выбор точности** в формах создания и редактирования алиаса (точно, `/18`,
  `/16`, `/14`) — чтобы исключение размером со страну было пригодным.
- **Превью маршрутов** — `GET /api/aliases/:id/client-routes` показывает, сколько
  маршрутов и байт реально получит клиент, и пересчитывается при смене точности.
- **Обновление в один клик** в таблице алиасов — перезабор сгенерированного
  списка из RIPEstat без входа в редактирование.

### Метаданные образа

Образы теперь объявляют собственные метки OCI. Будучи тонким слоем поверх
другого образа Cascade, они наследовали его `source` и `version`, из-за чего
опубликованный пакет никогда не мог привязаться к этому репозиторию.

## Быстрый старт

```bash
git clone https://github.com/smm959/cascade
cd cascade
docker build -t cascade .
```

Запуск с томом для данных — там живут панель, её база SQLite и сгенерированные
конфигурации туннелей:

```bash
docker run -d --name cascade \
  --cap-add NET_ADMIN --cap-add SYS_MODULE \
  --sysctl net.ipv4.ip_forward=1 \
  -p 8080:8080 \
  -v /opt/cascade/data:/etc/wireguard/data \
  cascade
```

Откройте `http://<host>:8080`, пройдите мастер первого запуска — Cascade создаст
первый интерфейс туннеля.

Подробное развёртывание, обратный прокси с TLS и справка по API — в каталоге
[`docs/`](docs/). Эти документы пришли из исходного проекта и остаются
актуальными.

## Что стоит знать

- **Параметры обфускации AmneziaWG симметричны.** `ContentPaddingAddition`,
  `RandomTrailers`, `Jc`, `S1–S4` и `H1–H4` должны совпадать на сервере и
  клиенте. Изменение только на сервере отключает всех, кто не переимпортировал
  конфигурацию — мы проверили это на себе. Считайте это операцией на всех
  устройствах сразу, а не правкой на лету.
- **IPv6 через туннель не работает.** Клиент направляет его внутрь, и там он
  истекает. Это осознанный размен, объяснённый выше.
- **Переимпорт конфигурации меняет только MTU.** Если устройство работает
  хорошо — не трогайте его: 1420 быстрее на пути в 1500 байт, а 1280 помогает
  только там, где путь меньше.
